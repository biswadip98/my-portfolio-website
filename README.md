# Biswadip Bhattacharjee — DevOps Portfolio

A personal portfolio website showcasing my work as a DevOps Engineer — automation, CI/CD, cloud infrastructure, and the tools I work with day to day.

🌐 **Live site:** _coming soon_

## About

Built as a fast, responsive, static website (HTML, CSS, JavaScript) and deployed on GitHub Pages. Covers my experience, tools, education, services, and contact details.

## Tech & Tools Featured

- **Cloud:** AWS
- **Ops:** Linux, Git, GitHub Actions, Docker, Kubernetes, Helm, Terraform, Ansible, Argo CD, GitOps, Grafana, Prometheus
- **Languages:** Java, Kotlin, Python

## Running Locally

1. Clone the repository.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
